Soalan lazim

Saya tak pandai komputer. Boleh guna ke?

Boleh. Semua diisi melalui borang pada telefon — sama macam isi maklumat dalam Facebook. Saya masukkan menu pertama anda, jadi anda cuma perlu edit bila ada perubahan.

Duit pelanggan masuk mana?

Terus ke akaun bank anda sendiri melalui Bayarcash. Saya tidak menyentuh duit anda langsung — saya tiada akses kepadanya.

Kena beli domain sendiri?

Tidak perlu. Anda dapat alamat di bawah orderdyno.my secara percuma. Kalau nanti nak domain sendiri, boleh disambung kemudian.

Kalau saya berhenti langganan, menu saya hilang?

Tidak. Menu anda boleh di-export sebagai fail sebelum berhenti, dan laman boleh dihidupkan semula bila-bila masa.

Berapa lama sampai siap?

Laman siap dalam beberapa minit. Yang ambil masa cuma isi menu — biasanya sejam kalau menu panjang.
